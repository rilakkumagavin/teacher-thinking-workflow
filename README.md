# 教材轉譯設計室｜從教師思考開始

AI 輔助教材轉譯與教學產品化工作流：五個循環、十個活動，先引導教師思考學生需求、學科脈絡與學習任務，再逐步完成作品、查核、試用與流程重測。

網站：https://rilakkumagavin.github.io/teacher-thinking-workflow/

## 如何使用

1. 選擇國語、自然或社會，從第一關開始。
2. 每關先思考、討論並留下紀錄，按「完成本關紀錄」保存完成狀態。
3. 由講師依現場進度提供密碼，網站不自行顯示或發送代碼。取得密碼即可開啟下一關，不以本機是否填完作為解鎖條件。
4. 講師提供最後一組密碼後，可在密碼欄輸入，統一解鎖全部步驟與最後的兩步驟製作彩蛋。
5. 全通關後可自由回看、修訂；筆記與解鎖進度儲存在目前瀏覽器，可匯出 Markdown 或備份／匯入 JSON。

講師帶領模式提供每活動的時間配置、引導語與初學／進階路徑。

## 科目差異

- 國語：依文體分析語句、段落、事件、意象或表達效果。
- 自然：依觀察、分類、條件與結果、構造功能、循環或系統建立關係，分清證據與結論。
- 社會：依空間、時間、人與環境、制度分工與人口變遷建立脈絡，保留限定語。

實際區塊與箭頭由教材決定，不固定套用三部分。網站中的通用例子是教學設計示意，不能當作特定課本事實或答案。

## 功能與資料

純前端靜態網站，不呼叫 AI API、不上傳教材或筆記、不自動登入外部服務。AI 任務由使用者複製後自行帶到選用工具。

闖關用於引導活動順序，並非帳號權限或教材安全保護。通關表示完成自填紀錄，不代表網站已評定內容正確、完成原頁查核或驗證教學成效。

修改筆記與切換科目會取消相關完成標記，但保留已解鎖關卡。舊版筆記可保留內容，從第一關開始闖關。

## 本機預覽與測試

在此儲存庫根目錄執行：

```sh
python -m http.server 8782
node 測試闖關.cjs
```

Windows 沒有 `python` 時可改用 `py`。瀏覽 http://localhost:8782/ 。字型無法連線時使用系統中文字型；剪貼簿受限時可手動複製。

## GitHub Pages

以 `main` 分支根目錄發布，無建置步驟。`.nojekyll` 保留靜態檔案原樣。

原兩步驟圖像學習單網站保留獨立運作，僅於最後彩蛋提供外部入口。
