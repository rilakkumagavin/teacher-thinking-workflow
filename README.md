# teacher-thinking-workflow｜示範跟做版

五循環、十活動。預設情境為四年級自然「地表環境會變動嗎？」。

## 本機啟動

在教材專案根目錄執行：

```powershell
py -m http.server 8765 --bind 127.0.0.1 --directory 網站\教師思考工作坊\網站原始碼
```

開啟 http://127.0.0.1:8765/ 。

## 互動方式

- 每關預先載入講師示範與草稿產出。
- 「採用示範」自動保存決定、依據、規格及產出；採用不等於教材已驗證。
- 只有點「我要自行調整」才展開四個選填欄位，修改即儲存、同步完整 Prompt。
- 無須寫反思、採用示範或輸入密碼即可閱讀下一關；瀏覽不會自動算採用。
- 每關可直接複製完整 AI Prompt，或下載本關成果與指令。
- 第十關保留獨立的教師最終審核；採用或調整任一關會撤回原審核狀態。
- 網站不會呼叫 AI、上傳教材或自動操作 ChatGPT。AI 執行與成果驗證需另行完成。

## 證據界線

示範根據本機既有擷取文字（印刷頁18–22／單元 PDF 第9–13頁）及待核對草稿整理。出版社、年份、版次、原 PDF 圖文待覆核；未進行本輪原頁驗證、實體列印或學生試作。

證據摘要與來源索引見 workshop.js。原教材沒有打包進網站。未取得原頁的 AI 任務只可產出草稿與待查清單。

## 保存與相容

資料格式為 version 4，仍使用原 localStorage key。第一次從舊版本遷移會保留一份 before-v4 備份（儲存可用時）。舊反思原文另列歷史筆記；舊解鎖資訊保存在 legacyProgress，不再限制閱讀。

舊筆記不會被推定為已採用新示範，也不會被推定為已驗證。匯入 JSON 會先驗證格式，再提示是否取代現有內容。

## 檢查

在專案根目錄執行：

```powershell
node 網站\教師思考工作坊\網站原始碼\測試決策筆記.cjs
node --check 網站\教師思考工作坊\網站原始碼\app.js
node --check 網站\教師思考工作坊\網站原始碼\workshop.js
```

測試闖關.cjs 及 journey.js 僅保留舊版邏輯參考，不再由網站載入。

## 圖片與 Skill 工作坊更新

第七關直接生成圖片式填空學習單，可選格數（整張合計或每個教學部分各自計算）與難度；練習尋找關聯時，出圖指令要求至少一半填空檢查概念連結。第八關以四個小步驟教學 Skill，附可下載範例與 NotebookLM 指令。第九關用四步流程比較同課重測。第十關整合從教材資料夾到上傳、分析、出圖、圖片/PDF下載及獨立答案的執行指令。

資料夾自動製作已以四年級自然第一單元實跑一次；參見「自動流程實測.html」。批次、跨帳號與失敗續作尚未驗證。Skill需由具備瀏覽器與本機工具的執行環境使用，靜態網站本身不執行自動化。所有圖片與答案仍待教師審核。公開包不包含教材PDF或私人筆記本、對話網址。
